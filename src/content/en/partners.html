Russian Versions of Your Clients’ Websites

For Web Agencies

We translate websites from English into Russian and check the Russian version after you publish it. One contractor for the entire Russian version: no need to find a translator and a Russian-speaking reviewer separately.

Become a Partner

Which Clients It Is For

For your agency’s clients who already receive Russian-speaking guests or want to attract them: clinics, hotels, resorts, shops, and other businesses. Russian is read by guests from Russia, Kazakhstan, Uzbekistan, Kyrgyzstan, and other countries.

Launch a Russian Version

For websites that do not have a Russian version yet. You send the text of the English version, we translate it into Russian, and after it is published we check the pages.

Check an Existing Russian Version

For websites that already have a Russian version. We check the text and how the pages work and send a list of errors with corrections. If the client decides to fix the technical errors, your agency gets an order for that work.

Three Services

The services can be ordered together or separately.

1. Translation into Russian

You send the text of the English version of the website as a file. If there is no file, send links to the pages and we will collect the text ourselves. We return the Russian text in the same format.

We also translate text in images. Your agency’s designer places it in the images.

2. Check of the Russian Text on the Website

  • the text is on the right page and in the right place;
  • nothing is missing: no fragments in English or another language, buttons, menus, and captions are translated;
  • the text is not cut off or duplicated;
  • the text reads correctly and clearly where it appears.

3. Check of How the Pages Work

  • links and page transitions lead to the correct Russian pages;
  • the language switcher opens the same page, not the homepage;
  • forms: we send a test request and you confirm it arrived; lists include the right countries and phone codes;
  • we compare contacts and prices with the English version and flag any differences;
  • Russian words fit into buttons and menus, and the layout is not broken.

We check on desktop and on mobile.

Questions and Answers

Do you translate websites?

+

Yes. For web agencies, we translate websites from English into Russian. After the text is published, we check the Russian version on the website. You can also order only a check if the Russian version already exists.

In what format should we send the text?

+

Send it in a file that your content management system can export, such as XLIFF or CSV. We will return the Russian text in the same format. If the text cannot be exported, send links to the pages.

What if an error cannot be fixed in the text?

+

Links, forms, and layout are fixed by your developer. We provide these errors as a separate list: where the problem is, what the visitor sees, and what needs to be fixed.

Do we need to sign a long-term contract right away?

+

No. You can start with one project. If our working format suits you, we can continue the cooperation and set permanent terms in an agreement.

Who does the work?

+

Native Russian speakers with experience in editing and proofreading.
