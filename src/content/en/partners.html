Questions and Answers

Do you translate websites?

+

No. Translation is done by your translator or a machine translation system. We edit the finished Russian text so it sounds natural and audit the published website from the perspective of a Russian-speaking customer.

In what format should we send the text?

+

Send it in a file that your content management system can export, such as XLIFF or CSV. After the audit, we will return the corrected file in the same format. If the text cannot be exported, send links to the pages.

What if an error cannot be fixed in the file?

+

Links, forms, and layout issues cannot be fixed in a text file. We provide these errors as a separate list for the developer: where the problem is located, what the customer sees, and what needs to be fixed.

Do we need to sign a long-term contract right away?

+

No. You can start with a pilot audit of one project. If our working format suits you, we can continue the cooperation and set permanent terms in an agreement.

Who audits the Russian website version?

+

Native Russian speakers with experience in editing and proofreading.
