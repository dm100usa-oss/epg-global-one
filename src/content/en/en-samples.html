Sample Documents

What You Receive

After the audit, the company receives three documents, each prepared for the people who will use it. Error numbers are the same in all documents, so the executive, editor, and developer are discussing the same issues.

Executive Report

Customer Trust in Website Score (CTWS), scores for five criteria, expert conclusion, pages with marked errors, and a full list of errors by importance: what should be fixed first.

Download Sample

Task List for the Website Editor

Text only: where it appears on the page, what is written now, and what to replace it with. No technical language, with a “Done” checkbox and space for the person responsible to leave a comment.

Download Sample

Task List for the Web Developer

Website functionality errors: page address and element, how to reproduce the issue, what happens now, and what is expected after correction. If requested, each issue can be provided as ready-to-use task text for a developer task-tracking system.
